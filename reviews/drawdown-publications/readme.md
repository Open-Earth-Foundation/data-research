# Project Drawdown Publications

[Project Drawdown Publications](https://drawdown.org/publications) — in-depth reports and analysis on climate solutions.

## Why we use it

- **Climate solution context** — sector-specific roadmaps (food/agriculture, gaming, etc.)
- **Methodology and framing** — science-based approaches to mitigation and adaptation
- **Cross-cutting themes** — climate–poverty connections, health/education, job function guides
- **Reference for Drawdown Explorer** — publications complement the Explorer’s solution data

## Data

- Reports and fact sheets (PDF, web)
- Topics: Clean Cooking, Black Carbon, Food/Agriculture, Climate–Poverty, Health & Education, Job Function Action Guides, Annual Outcomes
- Formats: PDF, web pages
- Access: [drawdown.org/publications](https://drawdown.org/publications)
